# Kassaan maksetun suorituksen siirtäminen ennakkomaksuksi

Kassaan maksetun suorituksen voi siirtää asiakkaalle ennakkomaksuksi eli saldoksi. Saldo käytetään automaattisesti laskujen maksamiseen laskutusajon yhteydessä.

## 1. Lisää suoritus tarvittaessa

Jos järjestelmässä ei vielä ole suoritusta, josta ennakkomaksu siirretään asiakkaalle, lisää uusi suoritus.

1. Avaa **Laskut → Suoritukset**.
2. Napsauta **Lisää suoritus**.
3. Valitse **Pankki tai kassatili numero** -kenttään kassatili ja täytä suorituksen **Rahamäärä**, **Kirjauspäivä**, **Maksupäivä** ja **Maksajan nimi**.
4. Napsauta **Tallenna**.

![Lisää suoritus -painike Suoritukset-välilehdellä](/img/pikaohjeet/kassasuoritus-ennakkomaksuksi.png)

## 2. Siirrä suoritus ennakkomaksuksi

Avaa tallennettu suoritus **Suoritukset**-välilehdeltä napsauttamalla sen **SuoritusID**-numeroa.

1. Napsauta **Liikasuoritus ennakkomaksuksi**.
2. Kirjoita **Asiakasnumero**-kenttään sen asiakkaan numero, jolle saldo siirretään.
3. Napsauta **Hae asiakas** ja tarkista, että haettu asiakas on oikea.
4. Kirjoita **Takaisin maksettava rahamäärä** -kenttään ennakkomaksuksi siirrettävä summa.
5. Napsauta **Tallenna ennakkomaksu**.

![Suorituksen siirtäminen ennakkomaksuksi ja asiakkaan valitseminen](/img/pikaohjeet/kassasuoritus-ennakkomaksuksi2.png)

## 3. Tarkista asiakkaan saldo

Avaa asiakkaan asiakaskortti ja tarkista, että ennakkomaksu näkyy saldona. Saldo käytetään automaattisesti laskujen maksamiseen laskutusajon yhteydessä.

Lisätietoja on [Saldon käyttö -ohjeessa](../ohjeet/yleiset_ominaisuudet/saldo.md#saldon-käyttö).
