# Laskut

## Laskujen tiedot

Asiakaskortin oikealla puolella olevassa **Laskut**-osiossa näet asiakkaan laskut. Osiossa näkyvät laskut, joissa asiakas on maksajana. Poistettuja laskuja ei näytetä. Jos asiakkaalla ei ole laskuja, näkyy teksti *Ei laskuja*.

Lista näyttää enintään 50 uusinta laskua, uusin ylimpänä. Otsikon vieressä oleva numero kertoo näytettyjen laskujen määrän. Jos laskuja on enemmän, löydät kaikki asiakkaan laskut [**Laskujen haussa**](/docs/uusi_versio/Laskut/laskujen-haku).

| Sarake | Sisältö |
|---|---|
| **Kynä** | Napsauta kynäkuvaketta, niin lasku avautuu muokattavaksi. |
| **Laskunro** | Laskun numero. Luonnoksella, jolla ei ole vielä numeroa, näkyy laskun sisäinen tunniste. |
| **Tilaus** | Laskun tilausten numerot linkkeinä. Napsauta numeroa, niin tilaus avautuu. Koontilaskulla voi olla useita tilauksia. |
| **Pvm** | Laskun päivämäärä. |
| **Eräpäivä** | Laskun eräpäivä. |
| **Summa** | Laskun summa. |
| **Tila** | Laskun tila (ks. alla). |

## Laskun tila

**Laskun tila.** Tila näkyy värillisenä merkkinä:

| Merkki | Merkitys |
|---|---|
| **Maksettu (vihreä)** | Lasku on maksettu. |
| **Avoin (keltainen)** | Lasku on maksamatta, mutta eräpäivä ei ole vielä mennyt. |
| **Erääntynyt (punainen)** | Lasku on maksamatta ja eräpäivä on mennyt. |
| **Hyvitys (vaaleansininen)** | Hyvityslasku tai hyvitetty lasku. |
| **Luonnos (harmaa)** | Lasku on luonnos, jolla ei ole vielä laskunumeroa. |

Avaa laskun tiedot napsauttamalla laskurivia tai kynäkuvaketta.

**Pitkä lista.** Lista näyttää ensin 10 uusinta laskua. Napsauta *Näytä kaikki N laskua,* niin näet kaikki ladatut. *Näytä vähemmän* palauttaa listan lyhyeksi.
