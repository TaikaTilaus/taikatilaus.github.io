# Muutosloki

Asiakaskortin **Muutosloki**-välilehdellä näet asiakkaan tietoihin tehdyt muutokset: mitä muuttui, kuka muutti ja milloin. Uusin muutos on ylimpänä. Jos muutoksia ei ole kirjattu, näkyy teksti *Ei muutoksia kirjattuna.*

Välilehden vieressä oleva numero kertoo listalla olevien rivien määrän. Lista näyttää enintään 200 uusinta riviä.

| Sarake | Sisältö |
|---|---|
| **Aika** | Muutoksen ajankohta. |
| **Kenttä** | Muutettu kenttä. Tilauksen, laskun ja ilmoitusvarauksen muutosten edessä näkyy kohteen nimi ja numero, esimerkiksi Tilaus 123: Päättymispäivä. |
| **Vanha arvo** | Kentän arvo ennen muutosta. Tyhjä arvo näkyy viivana (—). |
| **Uusi arvo** | Kentän arvo muutoksen jälkeen. |
| **Käyttäjä** | Käyttäjä, joka teki muutoksen. Automaattisten ajojen ja järjestelmän sääntöjen tekemissä muutoksissa käyttäjä on Järjestelmä. |
| **Mistä** | Mistä muutos tehtiin, esimerkiksi Asiakaskortti, Tilaus tai Omapalvelu. |

## Mitä lokiin kirjataan

Muutoslokiin kirjataan asiakkaan tietojen muutokset sekä asiakkaan tilausten, laskujen ja ilmoitusvarausten muutokset:

- [asiakaskortin](/docs/uusi_versio/Asiakkaat/asiakaskortti) tallennus: uusi asiakas (Asiakas lisätty) ja muuttuneet kentät
- alennukset ja alennussäännöt
- käyttäjätunnukset (kenttä Omapalvelu-tunnus)
- ryhmittelyt (kenttä Ryhmä: tyyppi)
- tilausten lisäys, muokkaus, peruutus, maksettu-tieto ja kestojatko
- laskut: luonti, lähetys, maksumuistutus, perintä, suoritusten kohdistus ja käsin tehdyt muutokset
- ilmoitusvaraukset: lisäys, muutokset, tila ja poisto.

Tilaukset näkyvät sekä silloin, kun asiakas on tilaajana, että silloin, kun hän on maksajana. Laskut näkyvät maksajan lokissa.

Salasanoja ei kirjata lokiin.
