# Ilmoitusvaraukset / myynnit {#ilmoitusvaraukset}

[Asiakaskortin](./index.md) oikealla puolella olevassa **Ilmoitusvaraukset / myynnit** -osiossa näet asiakkaan ilmoitusvaraukset ja myynnit. Osio näkyy vain ilmoitusten hallintaa käyttävillä.

Otsikon vieressä oleva numero kertoo varausten kokonaismäärän. Varaukset on järjestetty ilmestymispäivän mukaan, uusin ylimpänä. Poistettuja varauksia ei näytetä.

Osiossa näkyvät varaukset, joissa asiakas on varaajana tai maksajana.

| Sarake | Sisältö |
|---|---|
| **Varaus** | Ilmoitusvarauksen numero. |
| [**Myynti**](../../Ilmoitukset/myynti.md) | Myynnin numero. Napsauta numeroa, niin myynti avautuu. |
| **Tilaaja** | Tilaajan asiakasnumero pyöreänä merkkinä. Vie hiiri numeron päälle nähdäksesi nimen tai napsauta numeroa avataksesi asiakaskortin uuteen ikkunaan. |
| **Maksaja** | Maksajan asiakasnumero. Nimen näyttäminen ja asiakaskortin avaaminen toimivat kuten Tilaaja-sarakkeessa. |
| **Tila** | Varauksen tila värillisenä merkkinä. |
| **Julkaisu** | Julkaisun nimi ja numero. |
| **Ilmestyy** | Julkaisun ilmestymispäivä. Jos julkaisua ei ole, näkyy varauksen alkupäivä. |
| **Tuote** | Myyntituote ja ilmoitusosasto. |
| **Koko** | Ilmoituksen koko. |
| **Summa** | Varauksen summa ilman arvonlisäveroa. |

Rivi on korostettu, jos tilaaja ja maksaja ovat eri asiakkaat. Kun viet hiiren rivin päälle, näet selitteen **Korostettu: tilaaja ja maksaja ovat eri asiakkaat**. Osapuolet näkyvät **Tilaaja**- ja **Maksaja**-sarakkeissa.

Avaa [varaus](../../Ilmoitukset/ilmoitusvaraus.md) napsauttamalla riviä.

**Pitkä lista.** Lista näyttää ensin 10 uusinta varausta. Napsauta *Näytä kaikki N varausta*, niin näet kaikki ladatut. Lista latautuu enintään 200 uusimmasta varauksesta. Jos varauksia on enemmän, listan alla lukee *Näytetään 200 / N uusinta* varausta. Kaikki asiakkaan varaukset löydät [Ilmoitukset-listalta](../../Ilmoitukset/ilmoitukset-lista.md) valitsemalla asiakkaan.

Jos asiakkaalla ei ole varauksia, näkyy teksti *Ei ilmoitusvarauksia.*

Lisää uusi varaus napsauttamalla [*+ Lisää varaus*](../../Ilmoitukset/ilmoitusvaraus.md).
