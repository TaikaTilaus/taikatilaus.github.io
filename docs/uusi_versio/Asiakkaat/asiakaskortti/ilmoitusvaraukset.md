# Ilmoitusvaraukset / myynnit {#ilmoitusvaraukset}

Asiakaskortin oikealla puolella olevassa **Ilmoitusvaraukset / myynnit** -osiossa näet asiakkaan ilmoitusvaraukset ja myynnit. Osio näkyy vain ilmoitusten hallintaa käyttävillä.

Otsikon vieressä oleva numero kertoo varausten kokonaismäärän. Varaukset on järjestetty ilmestymispäivän mukaan, uusin ylimpänä. Poistettuja varauksia ei näytetä.

Osiossa näkyvät varaukset, joissa asiakas on varaajana tai maksajana.

| Sarake | Sisältö |
|---|---|
| **Varaus** | Ilmoitusvarauksen numero. |
| **Myynti** | Myynnin numero. Napsauta numeroa, niin myynti avautuu. |
| **Tila** | Varauksen tila värillisenä merkkinä. |
| **Julkaisu** | Julkaisun nimi ja numero. |
| **Ilmestyy** | Julkaisun ilmestymispäivä. Jos julkaisua ei ole, näkyy varauksen alkupäivä. |
| **Tuote** | Myyntituote ja ilmoitusosasto. |
| **Koko** | Ilmoituksen koko. |
| **Summa** | Varauksen summa ilman arvonlisäveroa. |

Keltaisella korostetut rivit ovat varauksia, joissa tilaaja ja maksaja ovat eri asiakkaat. Jos asiakas on vain maksajana, varauksen kohdalla on teksti *Tilaaja: [asiakkaan nimi]*. Jos varauksen maksaa toinen asiakas, on varauksen kohdalla *Maksajana*-merkki ja maksajan nimi.

Avaa varaus napsauttamalla riviä. 

**Pitkä lista.** Lista näyttää ensin 10 uusinta varausta. Napsauta *Näytä kaikki N varausta*, niin näet kaikki ladatut. Lista latautuu enintään 200 uusimmasta varauksesta. Jos varauksia on enemmän, listan alla lukee *Näytetään 200 / N uusinta* varausta. Kaikki asiakkaan varaukset löydät Ilmoitukset-listalta valitsemalla asiakkaan.

Jos asiakkaalla ei ole varauksia, näkyy teksti *Ei ilmoitusvarauksia.*

Lisää uusi varaus napsauttamalla *+ Lisää varaus*.
