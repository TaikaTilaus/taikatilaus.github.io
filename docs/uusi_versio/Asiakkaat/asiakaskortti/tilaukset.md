# Tilaukset

## Tilauksien tiedot

Asiakaskortin oikealla puolella olevassa **Tilaukset**-osiossa näet asiakkaan tilaukset. Otsikon vieressä oleva numero kertoo tilausten määrän. Tilaukset on järjestetty aikajärjestykseen, uusin ylimpänä. Osiossa näkyvät tilaukset, joissa asiakas on tilaajana tai maksajana.

| Sarake | Sisältö |
|---|---|
| **Kynä** | Napsauta kynäkuvaketta, niin tilaus avautuu muokattavaksi. |
| **Nro** | Tilauksen numero. Jos asiakas on tilauksessa vain maksajana, numeron vieressä on sininen Maksajana-merkki. |
| **Tuoteryhmä** | Tilauksen tuoteryhmä. |
| **Tuote** | Tilattu tuote. Jos tilauksen maksaja ja tilaaja ovat eri asiakkaat, tuotteen alla näkyy toinen osapuoli (ks. alla). |
| **Tila** | Tilauksen tila: esimerkiksi Voimassa, Tulossa voimaan, Nukutettu, Päättynyt tai Katkaistu. Tila näkyy värillisenä merkkinä. |
| **Alkaa** | Tilauksen alkupäivä. |
| **Päättyy** | Tilauksen päättymispäivä. |
| **Katkaisupäivä** | Tilauksen katkaisu- eli peruutuspäivä. Sarake näkyy vain, jos jollain tilauksella on katkaisupäivä. |
| **Hinta** | Tilauksen hinta. |
| **Maksettu** | Vihreä ruksi tarkoittaa, että tilaus on maksettu. Vie hiiri ruksin päälle, niin näet maksupäivän. Kellokuvake tarkoittaa, että tilauksen lasku on avoin. |

Avaa tilauksen tiedot napsauttamalla tilausriviä tai kynäkuvaketta.

**Pitkä lista.** Lista näyttää ensin 10 uusinta tilausta. Napsauta *Näytä kaikki N tilausta*, niin näet kaikki. *Näytä vähemmän* palauttaa listan lyhyeksi.

Jos asiakkaalla ei ole tilauksia, näkyy teksti *Ei tilauksia*.

Aloita uuden tilauksen lisääminen asiakkaalle napsauttamalla **+ Lisää tilaus** -painiketta. Tilauksen lisäys avautuu uuteen välilehteen.

## Tilaaja ja maksaja eri asiakkaita 

Jos tilauksen tilaaja ja maksaja ovat eri asiakkaat, rivi on korostettu **sinisellä**:

- Kun asiakas on vain maksajana, tilausnumeron vieressä on **Maksajana**-merkki ja tuotteen alla teksti *Tilaaja: [tilaajan nimi]*.
- Kun asiakas on tilaajana ja joku muu maksaa, tuotteen alla on **Maksajana**-merkki ja maksajan nimi.

Nimi on linkki, joka avaa toisen asiakkaan [asiakaskortin](/docs/uusi_versio/Asiakkaat/asiakaskortti) uuteen välilehteen.
