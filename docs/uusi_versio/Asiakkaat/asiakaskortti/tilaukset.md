# Tilaukset

## Tilauksien tiedot

[Asiakaskortin](./index.md) oikealla puolella olevassa **Tilaukset**-osiossa näet asiakkaan tilaukset. Otsikon vieressä oleva numero kertoo tilausten määrän. Tilaukset on järjestetty aikajärjestykseen, uusin ylimpänä. Osiossa näkyvät tilaukset, joissa asiakas on tilaajana tai maksajana.

| Sarake | Sisältö |
|---|---|
| **Kynä** | Napsauta kynäkuvaketta, niin tilaus avautuu muokattavaksi. |
| **Nro** | Tilauksen numero. |
| **Tilaaja** | Tilaajan asiakasnumero pyöreänä merkkinä. Vie hiiri numeron päälle nähdäksesi nimen tai napsauta numeroa avataksesi asiakaskortin uuteen ikkunaan. |
| **Maksaja** | Maksajan asiakasnumero. Nimen näyttäminen ja asiakaskortin avaaminen toimivat kuten Tilaaja-sarakkeessa. |
| **Tuoteryhmä** | Tilauksen tuoteryhmä. |
| **Tuote** | Tilattu tuote. |
| **Tila** | Tilauksen tila: esimerkiksi Voimassa, Tulossa voimaan, Nukutettu, Päättynyt tai Katkaistu. Tila näkyy värillisenä merkkinä. |
| **Alkaa** | Tilauksen alkupäivä. |
| **Päättyy** | Tilauksen päättymispäivä. |
| **Katkaisupäivä** | Tilauksen katkaisupäivä. Sarake näkyy vain, jos jollain tilauksella on katkaisupäivä. |
| **Hinta** | Tilauksen hinta. |
| **Maksettu** | Vihreä ruksi tarkoittaa, että tilaus on maksettu. Vie hiiri ruksin päälle, niin näet maksupäivän. Kellokuvake tarkoittaa, että tilauksen lasku on avoin. |

Avaa [tilauksen tiedot](../../tilaukset.md#tilauksen-ja-asiakaskortin-avaaminen) napsauttamalla tilausriviä tai kynäkuvaketta.

**Pitkä lista.** Lista näyttää ensin 10 uusinta tilausta. Napsauta *Näytä kaikki N tilausta*, niin näet kaikki. *Näytä vähemmän* palauttaa listan lyhyeksi.

Jos asiakkaalla ei ole tilauksia, näkyy teksti *Ei tilauksia*.

Aloita uuden tilauksen lisääminen asiakkaalle napsauttamalla [**+ Lisää tilaus**](../../tilaukset.md#uuden-tilauksen-lisääminen) -painiketta. Tilauksen lisäys avautuu uuteen välilehteen.

## Tilaaja ja maksaja eri asiakkaita 

Jos tilaaja ja maksaja ovat eri asiakkaat, rivi on korostettu. Kun viet hiiren rivin päälle, näet selitteen **Korostettu: tilaaja ja maksaja ovat eri asiakkaat**. Osapuolet tunnistat **Tilaaja**- ja **Maksaja**-sarakkeista.
