# Lisäkentät

Lisäkentät ovat kenttiä, jotka ylläpitäjä on määrittänyt erikseen [asiakaskortille](/docs/uusi_versio/Asiakkaat/asiakaskortti) kohdassa [**Asetukset → Lisätietokentät**](/docs/uusi_versio/asetukset/lisatietokentat). Ne näkyvät [asiakaskortin](/docs/uusi_versio/Asiakkaat/asiakaskortti) **Lisäkentät**-välilehdellä. Välilehden vieressä oleva numero kertoo käytössä olevien lisätietokenttien määrän.

Jos kenttiä ei ole määritetty, välilehdellä näkyy teksti Ei määriteltyjä lisätietokenttiä ja linkki Luo kenttiä täällä, joka avaa asetussivun.

Tietojen lisääminen tai muuttaminen:

1. Avaa asiakkaan [asiakaskortti](/docs/uusi_versio/Asiakkaat/asiakaskortti).
2. Siirry **Lisäkentät**-välilehdelle.
3. Täytä tai valitse tarvittavat tiedot.
4. Napsauta **Tallenna**.

Kentän tyyppi määrää, miten tieto syötetään:

| Tyyppi | Syöttötapa |
|---|---|
| **Teksti** | Vapaa teksti. |
| **Kokonaisluku** | Kokonaisluku. |
| **Desimaaliluku** | Luku, jossa voi olla desimaaleja. |
| **Päivämäärä** | Päivämäärä. |
| **Kyllä/Ei** | Valintaruutu. |
| **Valinta (lista)** | Valitse arvo valikosta. Valikon vaihtoehdot on määritetty asetuksissa. |

Jos kentän nimen perässä on punainen tähti (*), kenttä on määritetty pakolliseksi. Tyhjentämällä kentän ja tallentamalla voit poistaa aiemmin annetun arvon.
