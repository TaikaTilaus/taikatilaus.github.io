# Kaikki raportit

![Asiakkaat](/img/versio2/raportit.png)

**Kaikki raportit**-sivulla voit hakea, suodattaa ja avata järjestelmän raportteja sekä tallennettuja raporttihakuja. Avaa sivu yläreunan päävalikosta valitsemalla **Raportit** &rarr; **Kaikki raporit**.

## Raportin hakeminen

Kirjoita raportin nimi tai osa siitä **Hae raportin nimellä** -kenttään. Raporttiluettelo päivittyy automaattisesti kirjoittamisen aikana.

Voit rajata luetteloa myös seuraavilla valinnoilla:

| Rajaus | Kuvaus |
| --- | --- |
| **Kaikki ryhmät** | Rajaa raportit niiden ryhmän perusteella, esimerkiksi asiakkaisiin, ilmoituksiin tai kirjanpitoon liittyviin raportteihin. |
| **Kaikki lisääjät** | Rajaa raportit tai tallennetut haut niiden lisääjän perusteella. |

Voit käyttää nimihakua ja valikoiden rajauksia samanaikaisesti.

![Asiakkaat](/img/versio2/raportit2.png)

## Raporttiluettelo

| Sarake | Sisältö |
| --- | --- |
| **Nimi** | Raportin tai tallennetun haun nimi. |
| **Ryhmä** | Ryhmä, johon raportti kuuluu, esimerkiksi **Asiakkaat**, **Ilmoitukset** tai **Kirjanpito**. |
| **Viimeksi käytetty** | Ajankohta, jolloin raporttia on käytetty viimeksi. |
| **Lisääjä** | Raportin tai tallennetun haun lisääjä. |

Voit järjestää luetteloa napsauttamalla sarakeotsikkoa. Otsikon vieressä oleva nuoli näyttää lajittelusuunnan.

![Asiakkaat](/img/versio2/raportit3.png)

## Raportin lisääminen suosikiksi

Raporttirivin vasemmassa reunassa olevalla **tähtikuvakkeella** voit merkitä usein käyttämäsi raportin suosikiksi.

- Lisää raportti suosikkeihin napsauttamalla tyhjää tähteä.
- Poista raportti suosikeista napsauttamalla tähteä uudelleen.

Suosikkiraportit nuosevat listalla ylimmäksi.

![Asiakkaat](/img/versio2/raportit5.png)

Suosikkiraporttisi löytyvät myös omasta ryhmästä. 

![Asiakkaat](/img/versio2/raportit6.png)

## Raportin avaaminen

Avaa raportti tai tallennettu haku napsauttamalla sen rivillä olevaa **Avaa**-painiketta.

![Asiakkaat](/img/versio2/raportit4.png)

## Raportin käyttäminen

Kun avaat raportin, sivun yläosassa näkyvät raportin hakuehdot. Käytettävissä olevat hakuehdot vaihtelevat raportin mukaan.

Valitse haluamasi arvot hakuehtojen valikoista. Valitut arvot näkyvät valikoiden alapuolella sinisinä tunnisteina.

- Voit valita samaan hakuehtoon useita arvoja.
- Poista yksittäinen valinta napsauttamalla sen vieressä olevaa **X-painiketta**.
- Raportin tulokset ja kuvaaja päivittyvät valintojen perusteella.

Ota **Sama asiakas vain kerran** käyttöön, jos haluat saman asiakkaan näkyvän raportin tuloksissa vain kerran.

Tästä on hyötyä esimerkiksi silloin, kun sama asiakas kuuluu useaan raportille valittuun ryhmään.

![Asiakkaat](/img/versio2/raportti-haku.png)

## Kuvaaja

Raportin tulokset voidaan esittää kuvaajana. Kuvaajan oikealla puolella olevilla asetuksilla voit muuttaa tietojen esitystapaa.

Käytettävissä olevat vaihtoehdot vaihtelevat raportin mukaan. Kuvaaja päivittyy automaattisesti, kun muutat asetuksia.

Lataa kuvaaja kuvatiedostona napsauttamalla **Lataa kuva**.

![Asiakkaat](/img/versio2/raportti-kuvaaja.png)

## Data

**Data**-osiossa näet raportin tulokset taulukkomuodossa.

Taulukon yläpuolella oleva yhteenveto näyttää raportissa käytetyt hakuehdot ja tulosten rivimäärän. Yhteenvedossa näkyy myös, jos **Sama asiakas vain kerran** on käytössä.

Taulukon sarakkeet vaihtelevat raportin mukaan. Asiakkaisiin liittyvissä raporteissa voit avata asiakaskortin napsauttamalla **asiakasnumeroa**.

![Asiakkaat](/img/versio2/raportti-data.png)

### Datan käsitteleminen ja vieminen

Valitse ennen raportin tulostamista, lähettämistä tai viemistä, mitä raporttiin sisällytetään:

- **Liitä kaavio:** sisällyttää raportin kuvaajan.
- **Liitä Data:** sisällyttää raportin taulukkomuotoiset tulokset.

Voit valita joko molemmat tai vain toisen.

| Toiminto | Kuvaus |
| --- | --- |
| **Keräilylistaan** | Lisää raportin tuloksissa olevat asiakkaat keräilylistalle. |
| **Tulosta** | Avaa raportin tulostettavaksi. |
| **Kopioi** | Kopioi raportin tiedot leikepöydälle. |
| **Sähköposti** | Avaa raportin lähettämisen sähköpostitse. |
| **PDF** | Vie raportin PDF-tiedostoon. |
| **Excel** | Vie raportin tiedot Excel-tiedostoon. |
| **CSV** | Vie raportin tiedot CSV-tiedostoon. |
| **JSON** | Vie raportin tiedot JSON-tiedostoon. |
| **HTML** | Vie raportin tiedot HTML-tiedostoon. |

Tarkista raportin hakuehdot ja rivimäärä ennen asiakkaiden lisäämistä keräilylistalle tai tietojen viemistä.

### Raportin lähettäminen sähköpostilla

Voit lähettää raportin sähköpostin liitteenä yhdelle tai useammalle vastaanottajalle.

1. Valitse, sisällytetäänkö raporttiin **kaavio**, **data** vai molemmat.
2. Napsauta **Sähköposti**.
3. Kirjoita vastaanottajien sähköpostiosoitteet **Vastaanottaja(t)**-kenttään. Erota useat osoitteet toisistaan pilkuilla.
4. Valitse **Liitemuoto**:
   - PDF
   - Excel
   - CSV
   - JSON
   - HTML.
5. Kirjoita halutessasi saateteksti **Viesti (valinnainen)** -kenttään.
6. Tarkista vastaanottajat, liitemuoto ja viesti.
7. Napsauta **Lähetä**.

Sulje sähköpostitoiminto lähettämättä raporttia napsauttamalla **Peruuta**.

![Asiakkaat](/img/versio2/raportti-sposti.png)

## Hakuehtojen tallentaminen

Voit tallentaa usein käyttämäsi hakuehdot myöhempää käyttöä varten.

1. Valitse raportille haluamasi hakuehdot.
2. Napsauta **Tallenna hakuehdot**.
3. Kirjoita tallennetulle haulle kuvaava nimi **Haun nimi** -kenttään.
4. Valitse haun **Näkyvyys**.
5. Napsauta **Tallenna**.

Näkyvyys määrittää, ketkä voivat nähdä tallennetun haun. Esimerkiksi **Julkinen**-haku on muidenkin käyttäjien käytettävissä.

Tallennettu haku lisätään Raportit-sivun luetteloon. Kun avaat tallennetun haun, raportille asetetaan siihen tallennetut hakuehdot.

Voit sulkea tallennusikkunan tallentamatta napsauttamalla **Peruuta**.

![Asiakkaat](/img/versio2/raportit7.png)

## Palaaminen raporttiluetteloon

Palaa Raportit-sivulle napsauttamalla sivun oikeassa yläkulmassa **Palaa listaan**.
