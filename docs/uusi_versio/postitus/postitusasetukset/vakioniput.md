# Vakioniput

Vakionipuilla voidaan määrittää postitukseen vakiona mukaan tulevia nippuja esimerkiksi painolle, jakeluun, toimistolle tai muuhun erilliseen toimituspaikkaan.

Nippu lisätään postitukseen, kun:

- **Lehti** vastaa postitettavaa lehteä
- **Kpl** on suurempi kuin 0

:::info **Huomio:** 

Nippu-kenttään annetaan nipun numero tai muu koodi, joka toimii painon aineistossa nipun tunnuksena. Kentissä ei voi käyttää puolipisteitä tai sarkaimia.

 :::

![Uuden jakelualueen nimi, lehtivalinta ja lisätieto](/img/versio2/vakioniput.png)

### Vakionipun tiedot

Vakionipulle voidaan määrittää seuraavat tiedot:

| Kenttä | Selite |
| --- | --- |
| **Lehti** | Lehti, jonka postitukseen vakionippu kuuluu. |
| **Reitti** | Nipulle määritetty jakelu- tai kuljetusreitti. |
| **Jättöpaikka 1** | Ensimmäinen jättöpaikka tai siihen liittyvä tieto. |
| **Jättöpaikka 2** | Toinen jättöpaikka tai siihen liittyvä tieto. |
| **Nippu** | Nipun numero tai koodi. Tätä käytetään painon aineistossa nipun tunnuksena. |
| **Kuljetuksenohjaus 1** | Ensimmäinen kuljetuksen ohjaukseen käytettävä tieto. |
| **Kuljetuksenohjaus 2** | Toinen kuljetuksen ohjaukseen käytettävä tieto. |
| **Vastaanottaja** | Nipulle määritetty vastaanottaja. |
| **Osoite** | Nipulle määritetty toimitusosoite. |
| **Postinumero ja -toimipaikka** | Vastaanottajan postinumero ja postitoimipaikka. |
| **Jakelu** | Valitse nipulle **PÄIVÄ**- tai **VARHAIS**-jakelu. |
| **Kpl** | Nippuun lisättävien lehtien määrä. Jos määrä on 0, nippua ei lisätä postitukseen. |

Vastaanottajan nimi, osoite sekä postinumero ja -toimipaikka tulostuvat painolle muodostettavaan nipputiedostoon.

## Vakionipun lisääminen

1. Valitse **+ Lisää nippu**.
2. Täytä avautuvaan uuteen riviin nipulle tarvittavat tiedot.
3. Valitse **Tallenna**.

![Uuden jakelualueen nimi, lehtivalinta ja lisätieto](/img/versio2/vakioniput3.png)

## Vakionipun muokkaaminen

Voit muokata olemassa olevan vakionipun tietoja suoraan taulukossa.

1. Muokkaa haluamiasi kenttiä. Esim. kpl määrä 10 -> 20.
2. Valitse **Tallenna**.

## Vakionipun kopioiminen

Rivin oikeassa reunassa olevalla **kopiointipainikkeella** voit tehdä olemassa olevasta vakionipusta kopion.

Kopioitua riviä voi tämän jälkeen muokata tarpeen mukaan.

![Uuden jakelualueen nimi, lehtivalinta ja lisätieto](/img/versio2/vakioniput4.png)

## Vakionipun poistaminen

Poista vakionippu rivin oikeassa reunassa olevalla **roskakoripainikkeella**.
