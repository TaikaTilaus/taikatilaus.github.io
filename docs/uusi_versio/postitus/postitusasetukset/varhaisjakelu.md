# Varhaisjakelu

Avaa välilehti valitsemalla **Postitus → Postitusasetukset → Varhaisjakelu**.

## Varhaisjakelu lehdittäin

**Varhaisjakelu lehdittäin** -osio näyttää lehdet ruksilistana. Ruksaa ne lehdet, joilla on varhaisjakelu käytössä, ja paina **Tallenna**. Muutos vaikuttaa seuraavaan tilausten hakuun ja postitusajoon.

Jos varhaisjakelu on käytössä koko asiakkaalle (asetus **AAMUJAKELU_KAYTOSSA**), se koskee kaikkia lehtiä eikä lehtikohtaista valintaa tarvita.

## Katurekisteri

**Katurekisteri**-osio kertoo, mistä varhaisjakelun katuosoitteet luetaan (Postin katurekisteri).

Varhaisjakelun piirit (esim. Kyrönmaan Laihia, jonka PPP jakaa) kirjoitetaan painon CSV-nipputiedostoon omana nippunaan.
