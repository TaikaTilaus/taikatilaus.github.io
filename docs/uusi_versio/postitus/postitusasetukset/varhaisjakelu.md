# Varhaisjakelu

:::note Uusi TaikaTilaus

Tämä ohje koskee uutta TaikaTilausta (kehitysversio). Nykyisen TaikaTilauksen vastaavat ohjeet: [Varhaisjakelu](../../../ohjeet/asetukset/postitus/varhaisjakelu.md), [Varhaisjakelun reitit](../../../ohjeet/asetukset/postitus/varhaisjakelun-reitit.md).

:::

Avaa välilehti valitsemalla **Postitus → Postitusasetukset → Varhaisjakelu**.

## Varhaisjakelu lehdittäin

**Varhaisjakelu lehdittäin** -osio näyttää lehdet ruksilistana. Ruksaa ne lehdet, joilla on varhaisjakelu käytössä, ja paina **Tallenna**. Muutos vaikuttaa seuraavaan [tilausten hakuun ja postitusajoon](../postitusten-luonti.md).

Jos varhaisjakelu on käytössä koko asiakkaalle (asetus **AAMUJAKELU_KAYTOSSA**), se koskee kaikkia lehtiä eikä lehtikohtaista valintaa tarvita.

## Katurekisteri

**Katurekisteri**-osio kertoo, mistä varhaisjakelun katuosoitteet luetaan (Postin katurekisteri).

Varhaisjakelun piirit kirjoitetaan painon CSV-nipputiedostoon omana nippunaan.
