# Lisätietokentät

**Lisätietokentät**-sivulla voit luoda ja hallita asiakkaiden tietojen tallentamiseen käytettäviä vapaasti määriteltäviä kenttiä.

Tällä sivulla tehdyt muutokset vaikuttavat asiakaskortin [**Lisäkentät**-välilehteen](/docs/uusi_versio/Asiakkaat/asiakaskortti#lisäkentät).

Avaa sivu valitsemalla **Asetukset → Kaikki asetukset → Lisätietokentät**. Tai suoraan **Asetukset → Lisätietokentät**

![Lisätietokentät](/img/versio2/lisatietokentat.png)

## Uuden lisätietokentän lisääminen

1. Kirjoita kentän nimi **Nimi**-kenttään.
2. Tarkista automaattisesti muodostuva **Tekninen avain**.
3. Valitse kentässä käytettävä **Tietotyyppi**.
4. Valitse tarvittaessa **Pakollinen**, jos kenttä on täytettävä asiakaskortilla.
5. Napsauta **Lisää kenttä**.

Tekninen avain on kentän yksilöivä tunnus. Se muodostetaan automaattisesti kentän nimestä.

![Lisätietokentät](/img/versio2/lisatietokentat2.png)

## Määritetyt kentät

Sivun vasemmalla puolella näkyvät järjestelmään lisätyt kentät sekä niiden:

- nimi
- tekninen avain
- tietotyyppi
- pakollisuus.

Lisätty kenttä tulee näkyviin asiakaskortin **Lisäkentät**-välilehdelle.

Voit poistaa kentän napsauttamalla sen rivillä olevaa **roskakorikuvaketta**.

![Lisätietokentät](/img/versio2/lisatietokentat3.png)
